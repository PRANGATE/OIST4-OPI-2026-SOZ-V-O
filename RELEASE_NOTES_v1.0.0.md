# v1.0.0 — First Release

## Реализовано

- Создание, просмотр, редактирование и удаление записей о сне.
- Проверка обязательных полей и оценки качества от 1 до 5.
- Автоматический расчёт длительности сна с учётом перехода через полночь.
- Сохранение записей в localStorage.
- Статистика за 7 и 30 дней: средняя продолжительность, среднее качество и диаграмма.
- Настройка целевой продолжительности сна и отображение прогресса.
- Напоминание о времени сна через уведомления браузера.
- Экспорт дневника в CSV (sleep_diary.csv) с UTF-8 BOM и экранированием значений.

## Технические сведения

Приложение работает в современном браузере без серверной части. Данные остаются в локальном хранилище браузера.

## Известные ограничения

- Данные не синхронизируются между устройствами.
- Очистка данных сайта удаляет сохранённые записи и настройки.
- Напоминание срабатывает только при открытой странице и разрешённых уведомлениях браузера.
- Автоматические проверки GitHub Actions проверяют структуру, наличие файлов, синтаксис JavaScript и пробелы; полноценный набор функциональных автотестов не включён.
