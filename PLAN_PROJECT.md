# План проекта «Дневник сна» (Sleep Diary)

Лабораторная работа № 2 — планирование проекта и управление командой. Вариант 25.

## 1. Цель проекта

Разработать приложение «Дневник сна» для записи времени отхода ко сну и пробуждения, оценки качества сна, просмотра статистики, установки целевой продолжительности сна, настройки напоминаний и экспорта данных в CSV.

## 2. Организация работы

Проект выполняется одним студентом. В GitHub задачи назначены пользователю `PRANGATE`; метки ролей показывают основную функцию задачи, а метки сложности — её оценку. Роли используются для распределения ответственности в рамках учебного проекта, даже если фактический исполнитель один.

| Роль | Область ответственности |
|---|---|
| Менеджер проекта | Планирование, контроль сроков, документация и выпуск |
| Backend-разработчик | Модель данных, хранение, вычисления и экспорт |
| Frontend-разработчик | Экраны, формы, список записей, графики и настройки |
| QA-инженер | Функциональные проверки, граничные случаи и регрессия |
| Дизайнер | Макет интерфейса и пользовательские состояния |
