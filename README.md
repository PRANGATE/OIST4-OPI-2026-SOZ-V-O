# Дневник сна (Sleep Diary)

Учебный проект по дисциплине «Основы программной инженерии», вариант 25.

## Назначение

Веб-приложение для ведения дневника сна: фиксация времени отхода ко сну и пробуждения, оценка качества отдыха, анализ статистики и контроль личной цели сна.

## Реализованные возможности

- Добавление, просмотр, редактирование и удаление записей о сне.
- Автоматический расчёт длительности, в том числе при переходе через полночь.
- Локальное сохранение данных в браузере (localStorage).
- Статистика за 7 и 30 дней: средняя длительность, качество и диаграмма по датам.
- Настройка целевой продолжительности сна и индикатор прогресса.
- Напоминание о времени отхода ко сну через системные уведомления браузера (страница должна оставаться открытой).
- Экспорт всех записей в CSV с поддержкой кириллицы.

## Запуск

Серверная часть не требуется. Откройте файл `index.html` в современном браузере. Данные хранятся локально в браузере и не отправляются на сервер.

## Структура

- `index.html` — разметка интерфейса.
- `style.css` — адаптивное оформление.
- `script.js` — логика приложения и локальное хранилище.
- `.github/workflows/ci.yml` — автоматическая проверка при push и Pull Request.
- `database/schema.sql` — нормализованная схема SQLite.
- `database/seed_data.sql` — демонстрационные данные.
- `database/normalization.md` — обоснование нормализации до 3NF.
- `docs/database/er_diagram.svg` — ER-диаграмма.
- `docs/database/er_diagram.puml` — исходник диаграммы PlantUML.
