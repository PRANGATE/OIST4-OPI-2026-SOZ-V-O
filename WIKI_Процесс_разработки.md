# Процесс разработки — Дневник сна

## Назначение проекта

«Дневник сна» (Sleep Diary), вариант 25. Приложение предназначено для фиксации времени отхода ко сну и пробуждения, оценки качества сна, анализа статистики и формирования регулярного режима.

## Технологии

- HTML5 — структура интерфейса.
- CSS3 — адаптивное оформление.
- JavaScript — логика приложения.
- localStorage — локальное хранение записей и настроек.
- Git и GitHub — контроль версий, задачи и ревью.
- GitHub Actions — автоматическая проверка кода.

Серверная часть и передача личных записей на сервер не используются.

## Ветвление и Pull Requests

Каждая функциональность разрабатывается в отдельной ветке от main. Используется префикс feature/. После реализации создаётся Pull Request в main. В описание добавляется перечень изменений, проверки и ключевое слово Closes #N для связи с задачей.

Перед слиянием проводится self-review: просматриваются изменённые файлы, проверяются критерии приёмки и исправляются найденные замечания. В зависимости от объёма изменений используется Merge или Squash and merge.

## Автоматическая проверка

Workflow `.github/workflows/ci.yml` запускается при push в main и при Pull Request в main. Он проверяет наличие index.html, style.css и script.js, ключевые элементы HTML, синтаксис JavaScript командой node --check и ошибки пробелов командой git diff --check.

## Локальный запуск и проверка

Откройте index.html в современном браузере. Создайте запись, перезагрузите страницу и убедитесь, что данные сохранились. Для проверки перехода через полночь задайте время отхода ко сну 23:00 и пробуждения 07:00 — длительность должна составить 8 часов. Проверьте изменение и удаление записи, статистику за 7 и 30 дней, цель, CSV-экспорт и напоминание.

## Ограничения

Записи и настройки хранятся в localStorage конкретного браузера. При очистке данных сайта они удаляются. Напоминание работает, пока страница открыта, и требует разрешения браузера на уведомления. CI выполняет базовые проверки; функциональные тесты в отдельном тестовом фреймворке пока не настроены.
